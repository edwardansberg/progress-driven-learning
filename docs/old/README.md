# Historical documentation

Retained history preserves original meaning, conditions, assessments and decisions. It is not current policy or new authority.

Keep original attempts with their units; put corrections, later feedback and AI rewrites in separate labeled records. Unit evidence links retain the original date/version even when the current assessment changes. Do not relocate attempts merely because a unit is completed.

Use Git history when a source file need not remain in the working tree; preserve accessible versions for important evidence. Do not put active plans or current procedures here. Maintainer release evidence follows [the maintenance procedure](../ops/maintain-template.md#later-authorized-release-packaging); packaging must never erase the only copy.

No historical learner documents are supplied in this starter.
