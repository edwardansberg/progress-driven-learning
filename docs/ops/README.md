# Reusable procedures

- [Adopt or update](adopt-framework.md): Bring a reviewed learning-framework version into a workspace without replacing its learner history or local rules.
- [Maintain the framework](maintain-template.md): Scope framework changes, preserve development evidence and prepare a later neutral release under separate authority.
- [Sensitive material handling](../security/README.md): Apply when sources or evidence cross privacy/trust boundaries.
- [History](../old/README.md): Preserve original meaning; historical evidence grants no current authority.

Ordinary learning uses [the policy](../README.md) and [bundle conventions](../learning/README.md), with a brief closeout rather than a development runbook. Add another procedure only for a concrete recurring need; store it once with scope, prerequisites, actions, expected evidence and relevant failure handling.
